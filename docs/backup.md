# Backup System

## Overview

Centralized backup service that runs on each worker server, backing up all projects to S3-compatible storage.

## Architecture

```
┌─────────────────────────────────────────────────────────────┐
│                      Worker Server                           │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  /opt/ruilify/                                              │
│  ├── backup-service/         ◄── One backup service        │
│  │   ├── docker-compose.yml                                 │
│  │   ├── config.yml          ◄── Lists all projects        │
│  │   └── logs/                                              │
│  │                                                          │
│  └── apps/                                                  │
│      ├── projeto-1/                                         │
│      │   └── data/           ◄── Backed up                 │
│      ├── projeto-2/                                         │
│      │   └── data/           ◄── Backed up                 │
│      └── projeto-3/                                         │
│          └── data/           ◄── Backed up                 │
│                                                              │
└──────────────────────────┬──────────────────────────────────┘
                           │
                           │ Upload backups
                           ▼
              ┌────────────────────────┐
              │   S3-Compatible        │
              │   (DO Spaces, B2, etc) │
              └────────────────────────┘
```

## Backup Types

| Type         | Method        | Use Case                    |
| ------------ | ------------- | --------------------------- |
| **Volumes**  | tar + gzip    | Files, uploads, static data |
| **Postgres** | pg_dump       | Database backups            |
| **Redis**    | BGSAVE + copy | Redis RDB snapshots         |

## Configuration

### Global S3 Settings

Stored in ruilify settings (per worker or global):

```typescript
// In ruilify DB settings
{
  "backup_s3_endpoint": "nyc3.digitaloceanspaces.com",
  "backup_s3_bucket": "ruilify-backups",
  "backup_s3_access_key": "xxx",
  "backup_s3_secret_key": "xxx",
  "backup_schedule": "0 3 * * *",  // 3am daily
  "backup_retention_days": 7
}
```

### Project Backup Config

Generated automatically in config.yml:

```yaml
# /opt/ruilify/backup-service/config.yml
# Auto-generated by ruilify - do not edit manually

s3:
  endpoint: nyc3.digitaloceanspaces.com
  bucket: ruilify-backups
  region: nyc3

schedule: "0 3 * * *"
retention_days: 7

projects:
  - name: outline
    path: /apps/outline
    volumes:
      - data/uploads
      - data/attachments
    postgres:
      container: outline-db-1
      database: outline
      user: outline

  - name: n8n
    path: /apps/n8n
    volumes:
      - data/files
    postgres:
      container: n8n-db-1
      database: n8n
      user: n8n

  - name: redis
    path: /apps/redis
    volumes:
      - data
    # No postgres, just volumes

  - name: postgres
    path: /apps/postgres
    postgres:
      container: postgres-db-1
      database: "*" # All databases
      user: postgres
```

## Backup Service Container

### docker-compose.yml

```yaml
# /opt/ruilify/backup-service/docker-compose.yml
services:
  backup:
    image: ruilify/backup:latest
    container_name: ruilify-backup
    restart: unless-stopped
    environment:
      - S3_ENDPOINT=${S3_ENDPOINT}
      - S3_BUCKET=${S3_BUCKET}
      - S3_ACCESS_KEY=${S3_ACCESS_KEY}
      - S3_SECRET_KEY=${S3_SECRET_KEY}
      - TZ=UTC
    volumes:
      - ./config.yml:/config.yml:ro
      - /opt/ruilify/apps:/apps:ro
      - /var/run/docker.sock:/var/run/docker.sock:ro
      - ./logs:/logs
    labels:
      - "ruilify.service=backup"
```

### Backup Image

Simple container with:

- `crond` for scheduling
- `aws` CLI (or minio mc) for S3
- `pg_dump` for postgres
- `redis-cli` for redis
- `tar` for volumes

## S3 Structure

```
s3://ruilify-backups/
└── {worker-hostname}/
    ├── outline/
    │   ├── volumes/
    │   │   ├── 2024-01-15T030000Z.tar.gz
    │   │   ├── 2024-01-14T030000Z.tar.gz
    │   │   └── ...
    │   └── postgres/
    │       ├── 2024-01-15T030000Z.sql.gz
    │       ├── 2024-01-14T030000Z.sql.gz
    │       └── ...
    │
    ├── n8n/
    │   ├── volumes/
    │   └── postgres/
    │
    └── redis/
        └── volumes/
```

Naming convention: `{ISO-timestamp}.{extension}`

## Backup Process

### Daily Schedule (3am)

```bash
#!/bin/bash
# Executed by cron inside backup container

for project in $(yq '.projects[].name' /config.yml); do
  echo "[$(date)] Backing up $project..."

  PROJECT_PATH=$(yq ".projects[] | select(.name == \"$project\") | .path" /config.yml)
  TIMESTAMP=$(date -u +%Y-%m-%dT%H%M%SZ)

  # 1. Backup volumes
  VOLUMES=$(yq ".projects[] | select(.name == \"$project\") | .volumes[]" /config.yml)
  if [ -n "$VOLUMES" ]; then
    tar -czf /tmp/${project}-volumes-${TIMESTAMP}.tar.gz \
      -C ${PROJECT_PATH} ${VOLUMES}

    aws s3 cp /tmp/${project}-volumes-${TIMESTAMP}.tar.gz \
      s3://${S3_BUCKET}/${HOSTNAME}/${project}/volumes/

    rm /tmp/${project}-volumes-${TIMESTAMP}.tar.gz
  fi

  # 2. Backup postgres
  PG_CONTAINER=$(yq ".projects[] | select(.name == \"$project\") | .postgres.container" /config.yml)
  if [ -n "$PG_CONTAINER" ] && [ "$PG_CONTAINER" != "null" ]; then
    PG_DATABASE=$(yq ".projects[] | select(.name == \"$project\") | .postgres.database" /config.yml)
    PG_USER=$(yq ".projects[] | select(.name == \"$project\") | .postgres.user" /config.yml)

    docker exec $PG_CONTAINER pg_dump -U $PG_USER $PG_DATABASE | gzip > \
      /tmp/${project}-postgres-${TIMESTAMP}.sql.gz

    aws s3 cp /tmp/${project}-postgres-${TIMESTAMP}.sql.gz \
      s3://${S3_BUCKET}/${HOSTNAME}/${project}/postgres/

    rm /tmp/${project}-postgres-${TIMESTAMP}.sql.gz
  fi

  echo "[$(date)] Backup of $project complete"
done

# 3. Cleanup old backups
echo "[$(date)] Cleaning up old backups..."
# ... retention logic
```

```
  ● 2024-01-13 03:00 (241 MB)  ◄── Selected

What to restore:
  [x] Volumes (uploads, attachments)
  [x] Postgres database

⚠️  This will stop the project, restore data, and restart.
    Current data will be overwritten.

[Enter] Confirm restore    [Esc] Cancel
```

### Restore Steps

1. Stop project containers
2. Download backup from S3
3. Restore volumes (extract tar)
4. Restore postgres (psql < dump.sql)
5. Start project containers
6. Verify health

## Installation

### During Worker Setup

1. Backup service is installed during `setupWorkerServer()`
2. Default config.yml created (empty projects list)
3. S3 credentials from global settings

### When Project Deployed

1. Ruilify detects volumes and postgres in compose
2. Adds entry to backup config.yml
3. Restarts backup service to pick up new config

### When Project Removed

1. Ruilify removes entry from config.yml
2. Optionally deletes backups from S3 (with confirmation)

